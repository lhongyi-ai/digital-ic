# RTL simulation demo

24-second evidence-backed animation. No physical hardware is shown or measured.

Left: two actual CWRU validation windows and their integer model outputs checked against the Flash RTL regression. Right: synthetic ADXL345 SPI stimuli and powers decoded from a SEN1 log generated by the actual sensor RTL. The animation is explanatory, not a real-time waveform capture. It does not provide a new held-out test result.

Source snapshots and SHA256 hashes are retained in source_snapshots/ and metadata.json. Recreate from the project root with `.venv/bin/python scripts/make_simulation_demo.py`; requires local ffmpeg.
